# ki-risiko-check
Interaktiver KI-Risiko-Check für Berufe


## Gestaltung und Assets

Die Gestaltung folgt `DIL_CI-Manual_01.ai`: HK Grotesk (400/700), Überschriften 28/36 px, Fließtext 16/24 px sowie #004284, #80a1c2, #a1b3e5, #ff9900 und #facb99. Die große Einstiegsüberschrift skaliert responsiv.

DIL-Logo und Partner-/Förderlogos (EU-Kofinanzierung, Freie Hansestadt Bremen, m2c) stammen von https://impact-lab.eu/ und liegen unverändert unter `assets/`. Abruf: 17.11.2026.

HK Grotesk Regular und Bold: https://github.com/HankenDesignCo/HK-Grotesk (WEB/). Die SIL Open Font License liegt unter `assets/HKGrotesk-OFL.txt`. Alle Schrift- und Bilddateien werden lokal geladen.
